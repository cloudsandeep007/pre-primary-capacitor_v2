# Fee Operations SOP
## Daily Operations
1. **Manual Collection**: Accountant receives cash/UPI, opens Manual Entry UI, records transaction, verifies Receipt No.
2. **End of Day**: Admin Dashboard review of Total Amount Received vs Physical Cash/Bank statement.

## Academic Year Transition
1. Define new `fee_categories` if changed.
2. Create new `fee_structures` for the new year.
3. Bulk Assign structures to students based on their promoted class.

## Historical Data Entry
- Use Admin Bulk Import tool.
- Provide CSV matching the strict template.
- System validates Date, Student Roll No, Amount, Receipt No.
- Previews balances before confirming import.
