# Fee Reminders Workflow
## Concept
Inform parents about upcoming or overdue fees using the existing notification infrastructure.

## Rules
1. **No Online Payment Links**: Reminders are strictly informational.
2. **Channel**: Push / In-App notifications.
3. **Tracking**: Audit log when a reminder is triggered.
4. **Content**: "Tuition fee of ₹X is due on [Date]" or "Your fee of ₹X is overdue."
